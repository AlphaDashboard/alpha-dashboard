🚀 Alpha Dashboard — Complete Setup & Handover Guide

Step-by-step instructions for deploying the Alpha Dashboard application from scratch

Python 3.12 Django 6.0.3 PostgreSQL 18 GitHub: AlphaDashboard/alpha-dashboard August 2026
1
Prerequisites — Install Required Software

Install the following software before proceeding. All are free to download.

2
Clone the Code from GitHub

Open PowerShell and run:

# Clone the repository
git clone https://github.com/AlphaDashboard/alpha-dashboard.git

# Navigate into the project folder
cd alpha-dashboard
ℹ️
Repository URL: https://github.com/AlphaDashboard/alpha-dashboard
3
Create Python Virtual Environment & Install Dependencies
# Create virtual environment
python -m venv venv

# Activate virtual environment (Windows PowerShell)
.\venv\Scripts\Activate

# Install all required packages
pip install -r requirements.txt
✅
You should see (venv) at the start of your terminal prompt after activation.
4
PostgreSQL Database Setup & Data Restore

Step A — Create the Database

psql -U postgres -c "CREATE DATABASE alphadashboard;"

Step B — Restore the Database Backup

The backup file alpha_dashboard_backup.sql is shared separately. Place it on your computer, then run:

psql -U postgres -d alphadashboard -f "C:\path\to\alpha_dashboard_backup.sql"
⚠️
If psql is not found, add PostgreSQL to PATH: C:\Program Files\PostgreSQL\18\bin

Step C — Verify the Restore

psql -U postgres -d alphadashboard -c "\dt"

You should see tables like tblAccountmaster, tblUserMaster, tblCASHBANK, etc.

5
Configure Environment Variables (.env file)

Create a file named .env in the project root folder alpha-dashboard\.env with this content:

# Alpha Dashboard - Environment Configuration

DB_ENGINE=django.db.backends.postgresql
DB_NAME=alphadashboard
DB_USER=postgres
DB_PASSWORD=YOUR_POSTGRESQL_PASSWORD_HERE
DB_HOST=localhost
DB_PORT=5432
🔒
Important: Never share the .env file. It is in .gitignore and will never be pushed to GitHub.
ℹ️
A template .env.postgresql is already in the repo. Copy it and rename to .env, then fill in your password.
6
Run Migrations & Stored Procedures
# Apply database migrations
python manage.py migrate

# Install the stored procedure
python update_sp.py
✅
Expected output: PostgreSQL database detected... then SUCCESS: Stored Procedure updated!
7
Start the Application Server
python manage.py runserver

Open your browser and go to: http://127.0.0.1:8000/

9
Database Backup & Restore Guide

Create a Backup (Export)

pg_dump -U postgres -d alphadashboard -f "alpha_dashboard_backup_20Aug2026.sql"

Restore a Backup (Import)

psql -U postgres -c "CREATE DATABASE alphadashboard;"
psql -U postgres -d alphadashboard -f "alpha_dashboard_backup.sql"
💡
Take a backup before every major change. Store backups on Google Drive or OneDrive.
